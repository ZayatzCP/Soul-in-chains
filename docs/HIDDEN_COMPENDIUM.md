# The Hidden Compendium — дорожная карта

Расширение Arcane Artifacts: исследования, новые глифы и формы. Разработка идёт
по этапам ТЗ, каждый этап собирается и проверяется игровыми тестами в CI.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Где живёт | Внутри Arcane Artifacts (один мод, общий код и тесты). Исследования закрывают и пять существующих глифов аддона. |
| Механики, уже существующие в Ars | Улучшенные версии под новыми именами только там, где механика отличается: **Freeze** (накопление холода, полная заморозка, иммунитет), **Attraction/Repulsion** (по области от точки удара, у Ars Pull/Knockback действуют на одну цель относительно заклинателя), **Purification** (только вредное, Dispel снимает всё), **Detection** (импульс поиска существ, предметов и блоков; Sense Magic лишь подсвечивает магических мобов). **Не дублируются:** Linger, Rune, Orbit, Grow. Их изучают в исследованиях как известные принципы. |
| Скрытый раздел | Интерфейс Стола изучения в виде книги и раздел в книге Ars, страницы которого открываются по мере исследования. Код книги заклинаний Ars не трогается. |
| Формы | Beam и Chain — настоящие формы (первый глиф). Pulse и Aura — эффекты, несущие остаток заклинания, как Linger у Ars (`Self → Aura → Heal`). |
| Блокировка глифов | Миксин на `ScribesTile#setRecipe` (у Ars нет события) и запрет изучать предмет-глиф. Творческий режим не ограничен, отключается конфигом `research_gates_glyphs`. |

## Как устроены исследования (этап 2)

* Данные: `data/<namespace>/arcane_research/<id>.json` (формат описан в
  `ResearchDefinition.java`). Датапаки могут добавлять и заменять исследования.
* Состояния: неизвестно → обнаружено (выполнены предпосылки) → исследуется
  (образец изучен на столе) → принцип изучен (все эксперименты; выданы заметки)
  → глиф открыт (принцип сформулирован на столе) → глиф записан (игрок изучил глиф).
* Эксперимент засчитывается один раз, имеет несколько вариантов выполнения
  (`any_of`) и учитывается только после начала исследования.
* Триггеры: `spell_effect` (эффект глифа на существе или блоке), `spell_cast`,
  `effect_applied`, `observe`, а также свои триггеры новых глифов.
* Заметки (материалы, биология, магия, пространство) нужны для формулировки и не
  тратятся.
* Сервер решает всё: эксперименты считаются по серверным событиям, кнопки
  стола — проверяемые сервером нажатия меню. Клиент получает копию данных.
  Прогресс — сохраняемый аттачмент игрока, переживает смерть.
