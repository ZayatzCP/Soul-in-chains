# Arcane Artifacts — список предметов и блоков для дизайна

Все ассеты лежат в `src/main/resources/assets/arcane_artifacts/`. Текущие версии — временные
пиксель-арт заглушки. Их можно заменить файлами с теми же именами и размерами.

## Общие требования

| Тип | Размер | Примечание |
|---|---|---|
| Иконка предмета / глифа | 16×16 PNG | Стиль Ars Nouveau: пиксель-арт, фиолетовый, бирюзовый, золотой. |
| Иконка эффекта | 18×18 PNG | Показывается в инвентаре и HUD. |
| Сущность (ракета) | 16×16 PNG | Светится, полноярко. |
| Текстура блока | 16×16 PNG | Для модели блока. |
| GUI Стола изучения | 512×256 PNG | Книга занимает 352×236 в левом верхнем углу. |
| 3D-модели надетых предметов | Blockbench, формат Java Block/Item | См. `MODELS.md`. |

Глифы и иконки предметов выглядят как карточка Ars: фиолетовая рамка, пергаментный фон, символ в центре.

## 1. Предметы

### 1.1 Розовое золото
- **Файл:** `textures/item/rose_gold_ingot.png` (16×16)
- **Описание:** Сплав меди и золота, получается на верстаке (4 медных + 4 золотых слитка → 2 слитка). Нужен почти для всех аксессуаров.
- **Визуал:** Слиток розово-медного цвета с тёплым золотым блеском.

### 1.2 Венок манипуляции (голова)
- **Файлы:**
  - иконка: `textures/item/wreath_of_manipulation_vines.png` + четыре слоя цветов `textures/item/wreath_of_manipulation_flowers_1..4.png`;
  - надетая модель: `models/item/worn/wreath_of_manipulation.json` (+ текстуры `textures/item/worn/wreath_vine.png`, `wreath_flower.png`).
- **Описание:** Адаптируется к урону. После 5 попаданий одного типа урона (физический, огонь, лава, удушье, утопление, магия) даёт защиту на 3–6 минут. Регенерация и очищение от негативных эффектов.
- **Визуал:** Венок из лозы. Четыре группы цветов окрашиваются при адаптации:
  1. физический — серебристо-белый;
  2. огонь и лава — оранжевый;
  3. удушье и утопление — бирюзовый;
  4. магия — фиолетовый.
  Цвет задаёт игра через tint index, поэтому цветы рисуются **в оттенках серого**.
- **Важно:** при адаптации цвета светятся ярче, в покое они серые.

### 1.3 Фокусирующие ботинки (ноги)
- **Файлы:** иконка `textures/item/focusing_boots.png`; надетые `models/item/worn/focusing_boots_right.json` и `_left.json`. Слот `feet` добавляет мод: иконка пустого слота `textures/slot/empty_feet_slot.png`.
- **Описание:** Записывают заклинание с формой Самость. При приседании заклинание применяется на владельца за его ману.
- **Визуал:** Пара фиолетово-синих ботинок с золотой отделкой и бирюзовым камнем.

### 1.4 Фокусирующие перчатки (в руке)
- **Файлы:** иконка `textures/item/focusing_gloves.png` (она же модель в руке).
- **Описание:** Инструмент для каста, как книга или жезл. Записанное заклинание срабатывает дважды за стоимость одного; без формы летит как Снаряд.
- **Визуал:** Синие перчатки с фиолетовыми рунами на тыльной стороне и золотыми манжетами.

### 1.5 Перстень обратного импульса (кольцо)
- **Файлы:** иконка `textures/item/ring_of_reversal.png`; надетая `models/item/worn/ring_of_reversal.json`; текстуры `textures/item/worn/ring.png`, `gem.png`.
- **Описание:** Удары по владельцу накапливают заряд (до 100). Заряд превращается в ману.
- **Визуал:** Золотой ободок с фиолетовым камнем. Камень светится, когда заряд накоплен. Полоса заряда показана на предмете.

### 1.6 Мантия зеркального отражения (спина)
- **Файлы:** иконка `textures/item/mantle_of_reflection.png`; надетая `models/item/worn/mantle_of_reflection.json`; текстуры `textures/item/worn/mantle.png`, `clasp.png`.
- **Описание:** С шансом 15% отражает вражеский магический снаряд обратно стрелявшему.
- **Визуал:** Фиолетовый плащ с бирюзовой полосой и золотой застёжкой.

### 1.7 Стол изучения (блок и предмет)
- **Блок:** `models/block/research_table.json`, `blockstates/research_table.json`.
- **Предмет:** `models/item/research_table.json`.
- **Текстуры блока:** `textures/block/research_table_wood.png` (боковины), `research_table_top.png` (столешница), `research_table_book.png` (раскрытая книга сверху).
- **GUI:** `textures/gui/research_table.png` (512×256).
- **Описание:** Стол, на котором изучают предметы и образцы. Клик по столу открывает книгу: слева образец и его свойства, справа список исследований. Образец над столом медленно вращается.
- **Визуал:** Деревянный стол архидрева с отделкой из розового золота, на столешнице раскрытая книга с магическими кругами.
- **GUI:** пергаментные страницы в духе книги Ars. Слоты инвентаря и образца показаны квадратами 18×18. Не перекрывайте их, раскладка зашита в код.

### 1.8 Старый пергамент
- **Файл:** `textures/item/old_parchment.png` (16×16)
- **Описание:** Бумага, пропитанная Источником в Камере впитывания. Материал для блокнота.
- **Визуал:** пожелтевший свиток с фиолетовыми строками.

### 1.9 Тайный блокнот исследователя
- **Файл:** `textures/item/researcher_notebook.png` (16×16)
- **Описание:** Записи волшебника «???» — описания, лор и рецепты предметов мода.
- **Визуал:** кожаный блокнот, золотая рамка с фиолетовым камнем, бирюзовая закладка.

## 6. Что уже в проекте, но пока не спрайт

* `tools/generate_textures.py`, `tools/generate_research_assets.py` — генераторы текущих заглушек. После замены арта их **не запускать**: перезапишут файлы.
* `tools/import_models.py` — импорт 3D-моделей из Blockbench, инструкция в `MODELS.md`.
* `tools/blockbench/*_guide.json` — опорные модели частей тела для Blockbench (голова, туловище, руки, ноги).
